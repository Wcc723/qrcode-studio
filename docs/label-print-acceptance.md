# 印成 A4 標籤紙：實機列印驗收清單

自動化驗得到版面（每頁 210 mm 寬、格子位置跟型號數字相差 0.1 mm 以內、頁數、只印列印區）與截圖回讀，驗不到實體印表機：
縮放、印表機印不到的紙邊、送紙偏移、標籤紙的模切誤差與掃描槍讀不讀得到，都要用真的電腦、印表機與標籤紙看。
這份在 **Windows 的 Edge** 與 **Chrome** 各跑一次。改了 `src/pure/batch/paper.ts`、`src/pure/batch/labelSheets.ts`、
`src/components/batch/LabelSheets.vue` 的列印規則，或新增型號時再跑一輪。

本站只做瀏覽器列印（`@page` 加列印按鈕），**不產生 PDF 檔**。

## 準備

- 一台 Windows 10 或 11 電腦（有微軟正黑體、標楷體、新細明體），Edge 與 Chrome 都更新到最新版
- 一台雷射或噴墨印表機，A4 白紙，以及兩種標籤紙各一張：
  - **全版切割**：鶴屋 C3070 或龍德 LD-834（3 × 10、每格 70 × 29.7 mm，整張都是標籤）
  - **有留白**：鶴屋 L3464 或龍德 LD-818（3 × 8、每格 64 × 33.9 mm，四邊有留白）
- 一把尺；手機（掃 QR Code）與掃描槍（掃一維條碼，沒有的話用手機的條碼掃描 App）
- 測試清單：從 Excel 複製下面三欄（含欄名列、一個很長的名稱）

  ```
  財產編號	品名	保管單位
  TP-0001	筆記型電腦	總務處
  TP-0002	投影機	教務處
  TP-0003	國立臺灣大學醫學院附設醫院第二會議室	學務處
  TP-0004	雷射印表機	總務處
  ```

## 每個瀏覽器、每種標籤紙各跑一次

| # | 步驟 | 要看到 | Edge | Chrome |
|---|---|---|---|---|
| 1 | 打開 `/qrcode-studio/batch/`，貼上測試清單，輸出方式選「印成 A4 標籤紙」，選手上的型號 | 型號下方寫的格數、寬高與邊界跟包裝一致；預覽排出 4 格，每格是 QR Code 加三行字 | ☐ | ☐ |
| 2 | 「要印什麼」選「對位測試頁」，按「印對位測試頁」 | 開的是瀏覽器自己的列印視窗；預覽只有格線、格號與校正尺，沒有頁首選單、按鈕或說明文字；只有 1 頁 | ☐ | ☐ |
| 3 | 「更多設定」：紙張 A4、縮放「預設」或自訂 100、邊界「無」、「頁首和頁尾」取消勾選，用白紙印 | 沒有網址、日期、頁碼這些頁首頁尾 | ☐ | ☐ |
| 4 | 用尺量測試頁中間的校正尺 | 0 到 5 剛好 **5 公分**（容許 ±0.5 mm）。短了代表縮放不是 100% | ☐ | ☐ |
| 5 | 把白紙疊在標籤紙上對著光看 | 每一條格線都落在標籤的切線上（容許 ±1 mm）；差得多就量偏了幾 mm | ☐ | ☐ |
| 6 | 偏了的話在「位移微調」填偏差（內容偏左填正的左右、偏上填正的上下），再印一次測試頁 | 這次格線對上切線；記下填了多少 | ☐ | ☐ |
| 7 | 選回「標籤」，放標籤紙，按「列印標籤」 | 每一格的碼與字都在標籤裡面，沒有壓到切線；第 3 筆的長名稱以「…」結尾 | ☐ | ☐ |
| 8 | 全版切割那一張：看最外圈的格子 | 碼與字沒有被印表機切掉（離紙邊至少約 5 mm） | ☐ | ☐ |
| 9 | 手機掃每一格的 QR Code | 讀出 TP-0001 到 TP-0004 | ☐ | ☐ |
| 10 | 碼的種類改成 Code 128，「從第幾格開始印」填 5，用同一張標籤紙接著印 | 第 1 到 4 格沒有印東西，第 5 格起是條碼；掃描槍讀得出 TP-0001 到 TP-0004 | ☐ | ☐ |
| 11 | 勾選「記住這台印表機的位移」，重新整理頁面，再切到「印成 A4 標籤紙」 | 位移還在、清單不見了（本站不存清單） | ☐ | ☐ |
| 12 | 把縮放改成「符合頁面大小」再印一張測試頁 | 校正尺短於 5 公分：確認畫面上列印鈕下方的提示有講到這件事，照提示改回來就對了 | ☐ | ☐ |

## 另外各看一次

- **Mac 的 Chrome 或 Safari**：字型選標楷體或新細明體時，要看到「這台電腦沒有…」的提示；版面不跑掉、字不超出格子
- **手機**：預覽縮小到畫面寬度，可以捲動看完；按「列印標籤」會開系統的列印或分享面板（不要求在手機印得漂亮）
- **條碼太小會擋下**：碼的種類選 EAN-13、型號選龍德 LD-8101（7 × 16），要看到「條碼在這個格子裡太窄」並且列印鈕停用

## 回報

有打叉的項目，在 repo 的 issue 留言：瀏覽器與版本、印表機型號、標籤紙型號、哪一步、實際量到的數字（例如往右偏 1.5 mm），附照片更好。
請不要用真實的清單拍照。
