# 中英文版（`/en/`）

`AGENTS.md` 的「中英文版」放規則的重點，這份放做法、檔案與測試。

## AGENTS.md 的硬規則

2026-10-15 從 `AGENTS.md` 逐字搬來（#24：`AGENTS.md` 精簡到 20 KB 以下，免得超過 Codex 串接指令的上限）。
`AGENTS.md`「中英文版」只留摘要與指路，下面每一條的全文（做法、原因、`seo:audit` 驗哪些）和它一樣不可違反。

- **語系只看路由的 `meta.locale`**（英文路由才有 `'en'`）。`App.vue` 依它 provide 給整棵元件樹、同步 vue-i18n 的 locale、
  設 `<html lang>`；元件用 `useLocale()`（`src/i18n/locale.ts`）取，不讀網址。沒有 provide 時（單獨掛元件的測試）是繁中。
- **文案是型別化的字典，不放 vue-i18n 的 messages**：共用元件在 `src/locales/ui.ts`（繁中，進 entry）與 `ui.en.ts`（英文，
  只有英文頁 import，用 `provideUiCopy()` 交給底下的元件，英文字串不進 entry chunk）；條碼在 `src/locales/barcode.ts`；
  批次與標籤紙在 `src/pure/batch/copy.ts`；純函式自己的錯誤訊息（條碼檢查、連號、範本、逐列檢查、自訂尺寸、匯出）寫在各自的檔案，
  多一個 `locale` 參數、預設繁中。**繁中字串搬進字典時一個字都不改**。英文是給美國使用者寫的，不是逐字翻譯。
- **hreflang 只放在成對的頁**（`src/i18n/pairs.ts` 的 `PAGE_PAIRS`）：`zh-Hant-TW`、`en`、`x-default` 三條，兩邊互指；
  其他繁中頁維持只指向自己的一條 `zh-Hant-TW`。**`x-default` 指繁中那一頁**：沒有前綴的網址就是預設版，跟 hub
  （同一個網域的 `/` 與 `/en/`）一樣；`zh-Hant-TW` 只對得到台灣的繁中，香港、海外等其他中文使用者落到 x-default 也是中文，
  英文用的是不分地區的 `en`，各地的英文使用者都對得到。
- **語言跟著頁走**：`<html lang>` 是 `zh-Hant-TW`／`en`，`og:locale` 是 `zh_TW`／`en_US`，JSON-LD 的 `inLanguage` 同樣，
  `WebSite` 的 `name` 換成 `site.nameEn`（繁中名與舊名放 `alternateName`，網址都是同一個 `${site.url}/`），英文工具頁的價格寫 `USD`。
  `og:site_name` 用 `site.siteNameEn`，頁尾的商標聲明用 `site.trademarkEn`，回報問題連到問題回報的英文頁。
- **語言切換在頁首**：成對的頁連到另一個語言的同一頁，沒有對應頁就連到該語言的首頁（`switchTarget`）。
  手機在導覽那一排的最後；768 到 1023px 只留圖示（一排才放得下繁中的五個連結）。
- **GA 不分 property、不加參數**：兩種語言都是 `content_group: 'qrcode-studio'`，語言從網址前綴 `/qrcode-studio/en/` 分
  （每筆事件都帶網址）。批次的 `batch_download` 仍然只有三個字面值。
- **英文頁沒有的東西連到繁中**：英文頁尾「In Chinese only」連掃描器、WiFi、電子名片與教學；英文首頁只開網址一種（`GeneratorTool` 的 `only`）。
- `seo:audit` 驗：每頁的 hreflang 集合、`<html lang>`、`og:locale`、`inLanguage`、語言切換的連結；英文三頁的 title、H1、
  description 長度、`<main>` 裡沒有中文與全形標點、批次頁的目標字與錨文字；英文的批次文案、Letter 的 `@page` 與 Avery 同規格的型號不進 entry chunk。

## 範圍

| 繁中 | 英文 | 英文頁的重點 |
|---|---|---|
| `/` | `/en/` | 網址 QR Code 產生器（只開網址一種，沒有類型切換） |
| `/batch/` | `/en/batch/` | Bulk QR code and barcode generator：從 Excel 或 CSV 貼上、ZIP、印 Letter 標籤紙 |
| `/barcode/` | `/en/barcode/` | Barcode generator：Code 128、EAN-13、EAN-8、Code 39、ITF-14 |

其他類型頁（WiFi、vCard…）、`/scan/`、教學、常見問題、關於與隱私權頁都還只有繁中：英文頁尾的「In Chinese only」連過去，
那四個連結標 `hreflang="zh-Hant-TW"`，連結文字後面有 sr-only 的「(in Chinese)」，報讀器使用者點之前就知道會換語言；
英文頁的隱私說明連到 hub 的英文隱私權政策（`publisher.privacyUrlEn`），「About QR Code Maker」連到 hub 的英文介紹頁。

## 語系從哪裡來

1. `src/router.ts` 的英文路由帶 `meta: { locale: 'en' }`（三條都是動態 import，英文的說明文章不進 entry chunk）。
2. `App.vue` 依 `route.meta.locale` 算出語系，`provide(LOCALE_KEY)` 給整棵元件樹，同步 vue-i18n 的 `locale`，`<html lang>` 跟著換。
   SSR 與 client 走同一條路，所以預渲染的 HTML 與 hydrate 拿到的是同一個語系（`src/hydration.test.ts` 逐頁驗，英文三頁也在裡面）。
3. 元件用 `useLocale()` 取（`src/i18n/locale.ts`）。單獨掛元件、沒有 provide 時是繁中，原本的元件測試不用改。

## 文案放哪裡

| 檔案 | 內容 | chunk |
|---|---|---|
| `src/locales/ui.ts` | 共用元件的繁中文案（「?」、隱私那一行、產生器、外觀、預覽、下載、手機預覽列）與 `useUiCopy()`／`provideUiCopy()` | entry |
| `src/locales/ui.en.ts` | 同一份的英文；只有英文頁 import，在 setup 裡 `provideUiCopy(uiCopyEn)` 交給底下的元件 | 英文頁 |
| `src/locales/barcode.ts` | 條碼產生器的文案、每種碼制的用途與規則（`symbologies.ts` 從這裡組） | 條碼頁 |
| `src/pure/batch/copy.ts` | 批次頁的工具卡、檢查結果、下載、印標籤紙、對位測試頁 | 批次頁 |
| `src/pure/validateBarcode.ts` 等純函式 | 各自的錯誤訊息，中英並排；多一個 `locale` 參數，預設繁中 | 跟著用到的頁 |
| `src/layouts/DefaultLayout.vue` | 頁首、頁尾（英文版是另一段模板，繁中那段一個字都沒動） | entry |
| `src/locales/zh-TW.ts`、`en.ts` | vue-i18n 的 messages（目前只有幾個共用詞；vue-i18n 主要用來記目前語系） | entry |

為什麼不用 vue-i18n 的 `t()`：批次頁的字很多，要留在批次頁的 chunk；訊息大多帶參數與單複數（`3 rows`、`Row 3`），寫成 TypeScript 函式有型別檢查，
繁中的字串也能原封不動搬過來。entry chunk 只多頁首頁尾的英文與 `ui.ts` 的 provide／inject（v1.9.0 量到 gzip 多約 2.5 KB）。

## 英文版的批次與標籤紙

- **型號**：`src/pure/batch/labelSheets.ts` 的 `US_LABEL_SHEETS`。四個 Letter 型號跟 Avery 5160、5163、5167、22806 同規格，
  數字是 avery.com 範本頁提供下載的官方 PDF 範本裡每一格外框的絕對座標（點，1/72 in），跟同一頁 Word 範本的欄寬、欄距、列高對過，
  資料用點寫、換成 mm（`fromPt`）。另有一個 A4 21 格（63.5 × 38.1 mm，用龍德 LD-817 的版面）。預設 5160。
  A4 21 格沒有寫跟 Avery L7160 相容：拿不到 Avery 官方範本（avery.co.uk 與歐洲各國的 Avery 網站回 403，avery.com 沒有這個型號），
  格子位置對不了帳就不寫型號。
  Avery 是商標：畫面上只寫「Avery-compatible sizes」「laid out like Avery 5160」，不放標誌，批次頁的說明文章有一句商標聲明。
- **紙張**：`paper.ts` 的 `PAPERS`（A4、Letter 215.9 × 279.4 mm）。排版函式（`gridRight`、`gridBottom`、`contentBox`、`edgeCellCount`、
  `parseCustomGrid`、`sheetBox`）多一個紙張參數，預設 A4。`@page` 用 `pageRule(paper)`，兩條規則都寫死在 `paper.ts`，換紙張時列印區跟著換。
- **單位**：內部一律 mm；英文版的畫面用英寸：型號的尺寸與邊界、自訂尺寸的欄位（`parseCustomGrid` 的 `unit: 'in'`）、
  位移（0.01 in 一格、±`OFFSET_LIMIT_IN`，記住的位移照樣存 mm）、校正尺（2 in、刻度到 1/16 in）。條碼的窄條維持 mm 並附 mil。
- **自訂尺寸**：英文版可以選 Letter 或 A4。
- **字型**：Arial（預設）、Verdana、Times New Roman（`PRINT_FONTS_EN`）。
- **範本記號**：英文是 `{id}`（大小寫都認得），繁中照舊 `{編號}`，兩邊不混用。
- **EAN-13 的 20 到 29 開頭**：英文照 GS1 General Specifications 的 GS1 Prefix 表寫成 restricted circulation numbers（20 到 29 是「within a geographic region (MO defined)」，用法由各國的 GS1 決定；只限一家公司內部的是 04），不寫 reserved for in-store use。繁中照 GS1 台灣的前置碼表（020 到 029、040 到 049、200 到 299 都標「店內碼」）維持原句。`english.test.ts` 鎖兩邊的說法。
- **欄名**：`table.ts` 另外認得常見的英文欄名（Asset tag、Serial number、Part no.、Description、Location、Qty…），繁中照舊。

## 測試

- `src/i18n/i18n.test.ts`：成對的表、路由的 `meta.locale`、語言切換的目的地、hreflang、JSON-LD 跟著語言走。
- `src/pure/batch/english.test.ts`：Letter 型號的資料（格數、尺寸、每格在紙裡、對得上 Avery 官方 PDF 的座標）、英寸的自訂尺寸與位移、
  英文的錯誤訊息（條碼、連號、範本、逐列檢查）、英文字型、英文欄名。
- `src/en-pages.test.ts`：同一批元件在英文頁拿到英文（畫面上沒有中文，也沒有模板寫死的全形標點，例如「：」「，」）、Letter 的列印區（每張 215.9 mm、`@page` 是 letter、格子位置）、
  校正尺與位移用英寸、頁首頁尾。
- `scripts/seo/audit.mjs`：hreflang 集合與互指、`<html lang>`、`og:locale`、`inLanguage`、語言切換的連結、英文三頁的 title 與 H1、
  `<main>` 裡沒有中文與全形標點（U+3000 到 U+303F、U+FF00 到 U+FFEF）、英文的批次文案與 Letter 規格不進 entry chunk。
- `src/batch-gates.test.ts`：英文批次頁說「不存進瀏覽器的儲存空間」的每一句，都寫出「Remember this printer's offset」的例外。
- 共用元件裡分語系的標點：寫進字典（例如 `ui.ts` 的 `dockSep`），或照 `BatchTool.vue` 用 `locale === 'en' ? ': ' : '：'`，不要寫死全形。

**瀏覽器列印模式的量測沒有自動測試**（同 `docs/batch.md` 的驗收）：改 Letter 的型號或列印規則時，上線前用 Playwright 在 Chromium 與 WebKit
切到列印模式量 `.label-sheet` 是 215.9 × 278.9 mm（扣 0.5 mm）、抽 5160 與 22806 的格子位置跟型號資料相差 0.1 mm 以內。

## 新增一組成對的頁面

1. 寫英文頁（`src/pages/en/`），在 setup 裡 `provideUiCopy(uiCopyEn)`，`useSeoHead` 帶 `locale: 'en'`。
2. `src/router.ts` 加路由（動態 import、`meta: { locale: 'en' }`）。
3. `src/i18n/pairs.ts` 的 `PAGE_PAIRS` 加一組；`scripts/seo/audit.mjs` 的 `EXPECTED_PATHS` 與 `EXPECTED_PAIRS` 一起加。
4. 繁中那一頁的 hreflang 會自動多出 en 與 x-default（只有這個會變，canonical、title、description 不動）。
5. 英文頁要有分享圖時，`scripts/brand/cards.mjs` 加一張 `lang: 'en'` 的卡片再跑 `render.mjs`。
